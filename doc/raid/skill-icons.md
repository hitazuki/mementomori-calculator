# 角色详情技能图标

- 本地目录：`public/images/skills/`，保留100×100 PNG原图；当前188张，4,269,954字节（约4.07 MiB）。
- 默认来源：与角色头像相同的Moonheart远程资源镜像，路径为 `AddressableConvertAssets/Icon/Skill/CSK_{九位技能ID}.png`。这是远程资源目录，不是Git仓库；技能ID对应ActiveSkillMB/PassiveSkillMB。
- 共用映射：`src/constants/raid/skillIcons.js`，所有语言、技能等级和专武说明共用同一文件。
- 更新命令：`npm run sync:raid-icons`。与角色头像共用远程下载函数：已有文件跳过，仅下载缺失图片；共用超时、重试、PNG校验和临时文件写入。远程未提供时警告并在下次重试，网络或文件错误会令同步失败。
- `.github/workflows/sync-assets.yml` 在现有角色头像同步后同步技能图标，并将图片及映射纳入自动提交；无须CI持有本地解包目录。
- 已建模技能卡片及游戏内技能文本标题使用图片，并保留技能槽位角标。图片延迟加载、异步解码，加载失败时回退槽位文字。
- 已知例外：光士额外被动30005（P3）在2026-09-06本地及在线资源目录中均没有独立图标，保留P3文字；若后续远程提供该图，下次同步会自动纳入。普通攻击未建立经过确认的图标映射，沿用文字标识；常驻效果集合不是单个技能，不将S/P图标随意关联到效果上。
- 本次属于A类展示资源补全，不修改计算规则或角色技能行为。
