# ［黄金圣剑士］阿尔托莉亚规范化模型

- 身份：CharacterMB154，苍翠，战士，基础速度3272，物理普攻；采用Lv240/EX3。
- 复用分类C：回血事件、计数器、阈值伤害、状态及计时直接复用；新增通用 `otherLineupElementInCountAtLeast` 集合条件，表达“其他苍翠或天光友军合计至少2名”。

## 轮转与伤害

- S1「破魔圣剑」CD4。伤害前向最低HP比例友军广播一次主动回复事件，再给全队施加2次目标行动的可解除弱化效果抵抗率+30%状态；3目标720%物理攻击在单Boss上投影1段。
- S2「审判圣剑」CD4。伤害前向最低HP比例友军广播一次主动回复事件。当前回复计入累计次数后，未满15次为4×540%，达到15次为4×2160%。
- 默认无冷却缩减时轮转为S1、S2、普攻、普攻循环。
- 最低HP比例在满HP模型中按站位打破并列，不使用梅琳S1的手动低HP分支开关。

## 模型边界

- 主动回复量不计算；回复效果次数与接收目标保留，一次同时回复多人不重复计数。
- 魔法受击后圣剑光辉减层、被动回血、死亡解除不模拟；这些被动回复不广播主动回复事件。
- HP、魔防、减伤和弱化抵抗概率不进入当前木桩输出计算；各真实状态分别保留。
- 新集合条件在编译时拒绝空集合、未知属性和负数/非整数阈值；执行时排除本人后计数，页面详情五语说明集合和人数。
