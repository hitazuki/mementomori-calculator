# 规范化角色草案

复用等级 C：新增友方状态叠层及自身层数、存活敌人数、来源HP场景条件。保持木桩模型边界。

- 身份156，幽冥战士，速度2949，Lv240/EX3；普攻100%物理。
- S1 CD4：最高攻击前三敌，680/满10层1020%；单敌乘3、双敌乘1.5。固定敌人面板并列按站位。当前模式支持1/5敌。
- S2 CD4：随机5段580/满层870% ATK；满层追加最高攻击敌3段1500% STR且必暴。读发动前状态，技能自身不改变层数。
- roundStart：自身及固定攻击优先级前二其他友军各叠1层，HP至少50%再各叠1层；独立永久状态，上限10，每层5%输出增伤，不可解除，不计Buff数。
- battleStart：保留15600350401组合状态；命中与减伤不进入输出公式。
- 专武面板：LR防御贯通+7000、物魔贯通+7000；面板攻击百分比归一，不重复加算。
- 配置复用targetHpBelow50[156]，默认false；UI、详情与导出说明固定HP场景。
- 忽略敌方攻击后赎罪、减贯通、受击阻绝、死亡后持续触发、追加攻击无视屏障/免疫。
- 叠层结构：status.addStacks/maxStacks正整数；固定modifiers按最终层数乘算，在应用时冻结。禁止动态属性、符号项、攻击快照与叠层混用。按来源/目标/EffectGroup保存，重施刷新时间。
- 测试覆盖轮转冷却、满层时点、必暴开关、五敌、独立受益者历史、无效schema及旧角色回归。
