# 评分文案翻译

中文原始评审保留在角色评分数据中；本目录为繁体中文、英语、日语和韩语的静态译文，键是完整中文源句。覆盖评分依据、定位、技能分布、适用条件和机制标签。首版采用机器辅助翻译，结合游戏多语言 MB 核对技能及状态名称，并修订术语、数值和关键条件。译文不改变评分或机制输入。

修改评分文案后同步修改四种译文。运行 `node scripts/build_character_rating_locales.mjs` 生成按语言分包的公开资源；评分打包和生产构建也会执行此校验。新增或修改的源句缺译时构建失败，不复用旧句的译文。

测试覆盖全池完整性、百分比保留、占位符残留、英文/韩文中文残留，以及缓存与失败重试。除自动检查外，还需人工检查否定条件、触发概率、目标与次数、持续与补充方式；数字相同不代表译意正确。

浏览器仅在选择语言时加载对应静态包并缓存，不请求在线翻译服务。加载失败或旧缓存缺句时，整块评分文案回退中文并明确提示，避免同一段落静默混用语言；原始技能和专武描述仍使用各语言官方 MB。
