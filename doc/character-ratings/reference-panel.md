# 等效输出与等效生命公共基准 · 2026-10-30

本口径由用户确认，优先于README中的历史固定比例面板。实现唯一入口为 `src/utils/characterRatingPanel.js`，版本 `panel-reference-2026-10-30`。不沿用讨伐默认必暴，不修改讨伐计算。

## 面板与伤害

- 比例为公共面板含30%攻击/生命加成、未计角色专武及战斗技能时的比例：攻击1、生命2.5、力量/魔力/战技/耐力各0.2、防御/物防/魔防各0.2。四维派生到面板的收益无已验证公式时不额外补造；主属性伤害及主属性盾仍使用0.2。
- 双方防御、物防、魔防均600万；攻击方防御穿透11950、物魔穿透65700。计算绝对值可对应攻击3000万、生命7500万、四维各600万，但倍率计算不依赖这个绝对攻击单位。
- 双方Lv500。等级定数直接对应仓库CSV：DEF 834953、物防1382434、魔防1341126、防穿1725、物魔穿16660；不得将物防与魔防定数混同。
- 面板基础攻击/生命加成30%，专武百分比词条在同一面板区加算。攻击面板相对系数为 `(1+0.30+专武攻击)/(1+0.30)`；再乘技能加攻区 `(1+技能百分比加攻之和)`。来源攻击/生命/防御转模按明示来源和时点单独处理，不把旧来源快照数值当新面板技能百分比。
- 专武固定穿透先加到公共穿透，再接受适用的技能穿透百分比增幅；不是把固定穿透除以等级常数后加到技能百分比。每条通过率为 `Cdef / (D × Cpen/(P+Cpen)+Cdef)`，双路相乘；防御下降先作用于对应防御面板。
- 有效基础暴率沿用50%，不默认必暴。基础暴伤50%加额外60%，普通暴击倍率2.10，基准暴击期望1.55。专武、技能暴伤额外加入；明示必暴才使用100%暴率。缺评级换算依据的暴击/抗暴评级不冒充暴率。
- 基础额外增伤0%、无属性克制；合理属性配队满足角色文本要求，不默认添加外部队友增益或额外编队面板收益。

## 等效输出

基准分母为公共面板、无专武、无角色技能的100%攻击物理普攻伤害，基准暴击期望与双防均计入。所有角色、伤害类型使用同一个分母；魔法攻击按魔防定数结算，直接伤害按已确认适用乘区结算，不把它当成物理攻击。

等效倍率百分数 = 角色实际伤害 / 基准普攻伤害 × 100%。爆发和成熟均使用两行动平均，单敌、五敌总计分别保存；评分比较 `max(单敌, 五敌总计/3)`。完整冷却循环保留参考，不混入成熟窗口。

自伤/主动恢复爆发按4有效事件，成熟按满层；回合成长与技能锁按实际回合；到期或资源消耗允许成熟降低。未知事件频率不编造回合。

已知触发概率仅计算一次期望；同一状态的倍率强化、必暴、易伤等先一起算伤害，再对状态加权。未知条件可取明确上下状态伤害中点，不能将各乘区分别取中点再相乘，也不能对已知概率再额外减半。未知抵抗、随机分散不能自动变成50%折损。

艾谢例外沿用用户指定：S2每段1520%上限；其爆发加攻按4层40%，成熟6层60%。亚历珊卓155使用一次易伤施加的70%成功/30%失败状态参照：成功S1/S2均加40%易伤且S2为540%×10，失败均无易伤且S2为360%×10。不开启无证据的逐段重试；五敌逐目标覆盖未模拟，不能把这个状态参照称为精确覆盖率。

## 等效生命

基准角色公共生命记100%，双方双防、穿透按上表。相同伤害类型下，相对容量 = `(角色生命+实际可用盾)/基准生命 × 基准承伤/角色承伤`（盾与生命的适用减伤不同须拆开）。专武面板生命与技能生命分区；攻击盾按攻击/生命=0.4换算，主属性盾按主属性/生命=0.08换算。伤害生成盾从新的实际伤害重新计算。

物理/魔法分别保存；共同有限容量取较弱一路。开局、成熟、破盾、到期分别记录，不能把不同状态最大值相乘。伤害减免和独立阻绝按原技能渠道结算。治疗不加入单次致命容量；屏障、复活、不死、隐身/透明等按次数、时点与补充单独评审。没有统一来伤频率，不编造每回合治疗、受击或反击次数。

持续生存应同时评审有效防护覆盖与到期后的能力，不能仅凭最终到期状态抹去长时防护。朝日专项修正：前10回合去盾物理359%、魔法245%，无治疗/补盾、第11回合后100%，综合持续生存5分；不将一次完整盾计入持续底座。结构记录sustainWindow及afterExpiryReference，明确有限期限，不假造战斗长度或每回合承伤权重。

## 评分与审计

当前输出1–10分下界为10/200/400/700/1100/1700/3000/5000/8500/14000%，爆发与成熟共用；有限生命容量1–10档下界为105/115/130/150/180/220/300/400/600/800%。输出是整数能力档，不是线性伤害比例；防御最终分还需时效和非容量机制复核。固定阈值不随第一名自动缩放。

全池新旧倍率、分数、分布和封顶检查见 `v6/panel-recalibration.md`。基线 `v6/panel-baseline.json` 固定为本次面板更新前的本地评分，区别于远端历史9ef07af基线；辅助、防护、控制三维有独立哈希保护。v5计算与旧v6阶段仍为历史证据，当前发布输出以outputCalibration、生命以survival.states为准，旧生命留在legacyStates，不刷新源哈希绕过复核。
