# AI 角色能力评分 v4

评分与讨伐配置、编译器、运行时完全独立，仅共享角色概览中的 MB 原文和专武资料，不改变讨伐结果。

## 评分口径

134 名角色统一按满级技能、最高阶段专武比较。初版已逐个阅读全部技能与专武；v2 对全部角色重新进行 0–10 整数档校准，并重划功能归属、复核受影响原文、编写主要机制标签。不是将旧分数乘二。分数、804 条逐轴依据、条件和标签保存在 reviews.txt。

这是 AI 文本评审加代表场景计算，不是战斗模拟或完整面板计算。倍率、覆盖人数、概率、持续时间、速度、冷却、启动回合、属性限制、自损和面板来源用于定性比较；不能用词条存在或百分比大直接生成分数。无专武不补造，不计账号秘仪。互斥条件不同时按上限计算。

## 六个作用维度

| 维度 | 纳入范围 | 边界 |
|---|---|---|
| 单体输出 | 单目标伤害、追击、自增伤、直接及持续伤害 | 条件与启动折价，不同伤害基准不直接相加 |
| 群体输出 | 多目标伤害、覆盖、扩散、持续伤害 | 随机多段不等同每个目标完整连击 |
| 自身生存 | 自身防御、护盾、减伤、阻绝、免疫、复活、回复 | 反伤不等于减伤；自身受益不计团队防护 |
| 团队防护 | 友军防御、治疗、净化、代承伤，以及降低敌方攻击、输出、暴击、贯通、命中 | 脱力、输出下降、减攻均在此，但乘区不同 |
| 进攻辅助 | 友军加攻、暴击、命中、加速、减冷却，以及敌方减防、易伤、驱散、增益免疫、回复抑制 | 减疗不是行动控制；自身增益主要计输出 |
| 行动干扰 | 晕厥、沉默、沉睡、禁锢、减速、冷却恢复延缓 | 减速与硬控分档；挑衅主要计防护；复制不默认硬控 |

同一效果可以有不同方面的真实贡献，例如吸攻同时改善自身输出和团队防护。但不能仅因效果是异常就给进攻辅助和行动干扰加分。六轴不求和，不输出综合排名。

## 统一 10 分标准

| 分数 | 跨角色含义 |
|---|---|
| 0 | 无该类有效贡献 |
| 1–2 | 微弱、附带贡献 |
| 3–4 | 有限，或覆盖及条件苛刻 |
| 5–6 | 有效，能承担部分职责 |
| 7–8 | 突出，能承担主要职责 |
| 9–10 | 当前角色池的顶尖能力参考，仍有条件 |

分数是序数判断，不代表等距收益、胜率或小数级精度。同档中稳定性、覆盖和启动更优者优先上档；不为增加区分度随意分配奇数。9–10 不保证所有场景都更强，也不是该角色自身的最佳能力就能获得满分。

参照：原版科迪单体 9，梅琳进攻辅助 9，圣剑福尔蒂娜团队防护 10，雪幻露娜琳德行动干扰 9。福尔蒂娜受来源面板与轮转影响，露娜琳德受暴击、冷却和免疫限制。基础攻击角色保留微弱输出，不用零分表示没有攻击行为。

## 乘区边界

- 加攻减攻属于攻击乘区。来源面板加攻需比较来源与受益者面板，不等于受益者同百分比增幅。
- 脱力是独立于加攻减攻的乘算因素，不能按百分点相减。
- 输出伤害下降属于增伤减伤乘区。露莎卡的该效果、尤里卡的打叉叉不等于脱力，也不能直接当成固定比例最终减伤。输出提升、承受伤害变化同样标识增伤减伤乘区；标签不替代具体叠加规则。
- 减防、贯通收益随敌防、贯通、等级非线性变化。80%减防不是固定80%增伤。
- 暴伤考虑暴击率、原有倍率与相关减免，不默认必暴。
- 阻绝、伤害截断、屏障与减伤分开标注。

以上用于约束评审，v3 增加了下述代表场景乘区计算，但不宣称已完成完整角色面板与所有机制模拟。脱力和输出下降乘区依据为本次用户明确纠正，MB 原文快照另行保留。

## 机制标签

标签描述效果类型，雷达描述实际作用，二者不一一对应。四组为增益、异常、恢复、其他机制。恢复及驱散、复制、冷却等另列。分类是图鉴编辑标签，不是引擎状态枚举。

每个标签由评审者显式编写并引用 S1/S2/P1/P2/W/stats，不通过关键词生成。标签是主要机制摘要，并非完整建模清单，也不表示无条件生效。点击标签可在原文区域核对目标、数值与条件；作用于自身还是友军，以原文及评分理由为准。

## 生存校准补充（2026-09-07）

先看抗爆发容量，再看保护覆盖与续航。普通回血、再生、吸血均主要提供持续恢复，不按独立减伤或生命上限评价。吸血额外侧重反伤对抗，但必须存活并造成有效伤害；普通回血则取决于施放时机与恢复来源。过量治疗不累积为额外抗爆发容量，也不默认恢复可以抵消致命伤害。复活、明确的致命保命回血属于特殊保命机制，和普通回血分别评估。

- 无其他生命加成、相同来伤时，生命+100%将生命容量变为2倍，粗略等价独立50%伤害阻绝的承伤容量。已有同区生命加成时，应比较增益前后生命比例，而非继续当独立翻倍。
- 在上述参照下，生命+40%为1.4倍容量，等效独立来伤降低约28.6%。防御+100%需另按非线性防御通过率理解，不等于50%独立减伤。
- 护盾先换算为生命容量：攻击倍率盾 / 当前最大生命值。以攻击:生命=1:3作粗略参照，300%攻击盾约100%生命盾，1000%攻击盾约333%生命盾。这是用户提供的估算参照，不是已计算的标准面板；生命加成、叠攻、来源不同都会改变比例。
- 护盾还应考虑首发时间、持续及补发间隔、解除、绕过与第几回合停止。不能将多次护盾相加成开局生命，也不能无条件等同永久生命上限。
- 增伤减伤乘区、独立阻绝、生命容量分别评估，不把“等效承伤能力”误写成相同计算机制。

本轮核对同类生存理由，未发现仅凭吸血进入9档的其他角色；其余高分还须有阻绝、生命或屏障等主机制。v3统一乘区校准后：萨宾娜70为6（生命40%与防御100%相乘）；芬里尔83为7（60%独立阻绝为主，普通恢复是续航）；梅尔林135为9（周期1000%攻击盾与30%承伤降低、防御150%组合，保留第13回合停止补盾限制）。这些仍是AI序数评审，不是由等效容量机械映射出的精确分数。

## v3 乘区参照与重评

生存输入在 survival-profiles.json（36名）；自增益输入在 offense-profiles.json（72名）。这些是逐条核对后显式编写的条件快照，脚本只计算乘区结果，不从文本提取数值、不自行分配分数。每个快照保留来源与评审结论。其余角色没有可合并的本轮参照时维持原有文本评审，不以缺失当无收益。来源型叠加顺序、复制、无限成长、受击阈值阻绝等未确认机制不硬塞入通用乘式。

### 生存

v4 生存参照固定有效防御/定数比1、攻击/生命1/3，仅改变敌方增伤：0%无克制、25%属性克制、100%压力测试。前两者为常规比较，第三者只说明极端敏感性，不参与常规分数降档。不是角色真实面板。

- 生命容量 H = 1 + 生命增幅 + 来源攻击生命倍率 × 攻击/生命。
- 一条防御路的承伤容量比 = (1 + x × (1 + 防御增幅)) / (1 + x)。防御与物魔防御分别计算；物理和魔法来伤分列。
- 增伤减伤路容量比 = (1 + 已有增伤) / (1 + 已有增伤 - 承伤降低)。不等同独立阻绝。
- 独立阻绝容量比 = 1 / (1 - 阻绝比例)。仅全额阻绝采用此式；超出生命阈值部分的阻绝、次数屏障、致命保命不套此式。
- 盾容量 S = 攻击盾倍率 × 攻击/生命 × (1 + 当前攻击增幅) + 生命盾倍率 × H。
- 当前满盾承伤容量 = (H + S) × 防御路 × 物魔路 × 增伤减伤路 × 独立阻绝；无盾列取 S=0。

来伤基准为同一假设面板移除本组效果后的承伤容量，不是实际生命值。普通回血、再生、吸血未乘入容量。开局、条件成立和到期分别列快照，不对互斥状态求和，不将补发次数累加为首击容量。未列出的抗暴、闪避、净化、屏障等由文本评审补充。

### 输出自增益

参照三组敌防/定数为0.25、1、4；已有加攻0%、50%、100%；已有增伤0%、50%、100%；暴率20%、50%、80%；暴击倍率1.5、1.5、2；贯通/定数固定1，生命/攻击固定3，防御/攻击0.25、0.5、1。

- 攻击收益 = (1 + 已有加攻 + 本组加攻 + 来源生命倍率 × 生命/攻击 + 来源防御倍率 × 防御/攻击) / (1 + 已有加攻)。来源快照归一化需要明确前提，不递归放大来源，也不将未确认先后顺序的多个来源型增益强行叠加。
- 增伤收益 = (1 + 已有增伤 + 本组增伤) / (1 + 已有增伤)。与攻击收益相乘，同区加攻彼此相加。
- 暴击期望 = 1 + 暴率 × (暴击倍率 - 1)，比较增益前后比值。暴率上限1；必暴时不重复叠暴率收益。
- 一条防御路收益 = (1+x) / [1 + x × (1-减防) × (1+p) / (1+p×(1+贯通增幅))]，其中x为增益前有效防御/定数，p为原贯通/定数。两路分别算，不把贯通百分点直接当伤害百分点。
- 自增益收益为攻击、增伤、暴击期望、两防御路收益相乘。

这是同一技能移除本组效果前后的边际收益，不是跨角色伤害排名。只适用于相应的攻击基准、可暴击且受防御影响的伤害；力量/魔力直接伤害、生命比例伤害、反伤等不得照乘。技能倍率、段数、目标数与轮转继续从原文判断，不重复乘进“自增益收益”。暴击后追击、首暴后必暴与伤害过程中的增益触发未假设为独立固定暴率。

### 分数如何使用结果

同一量表仍为0–10序数判断。先比较常态与主要工作窗口的组合收益，再结合原有倍率/段数、覆盖与条件重评；不使用最大快照自动映射分数。满层强、启动慢的角色不会凭满层值自动满分。36项生存、72组单体/群体评分均复核，可维持原分但保留新依据。截图三例在中性参照下：萨宾娜无盾2.10倍，芬里尔无盾2.50倍，梅尔林补盾后约9.48倍、无盾约2.19倍。普通续航不能将前两者再机械放大。

三种参照、乘式与每个状态的原文保留在评分数据中供复核；详情页仅展示雷达图、分数、简短依据、机制标签与关键条件，不展示计算面板或重复技能原文。标为text-review-with-reference-calculation的记录同时保留输入、场景和计算结果；只有文字评审的记录仍标text-review-only。重评不改变讨伐结构或结果。当前仍未纳入完整角色基础成长面板，这是本轮计算的明确限制。

### 列表评分索引

每次生成或修改评分后运行 `node scripts/audit_character_ratings.mjs`，同时更新状态报告与 `public/data/character-ratings/index.json`。已有 Master 数据同步 Action 也执行此步骤。列表仅在选择评分排序时加载该索引，按所选维度降序、同分按角色 ID 排序；未评分置后，源数据变更的旧评分标记为待复核。索引不生成或推断新角色分数。


## v4 生存校准规则（优先于历史 v3 复核结果）

本轮范围与分数变化见 [survival-v4-review.md](survival-v4-review.md)。评分仍是有数值参照的编辑分，不是精确的自动战斗评分。以下约束必须用于所有后续角色，不能对阻绝使用最高值、对减伤却只使用压力值。

1. **统一场景**：同时比较无克制0%增伤和克制25%增伤，不假设所有攻击都克制。100%增伤仅压力测试。来源为本轮用户指定常规环境及全池文本筛查，未用出场率推导概率。防御、攻击/生命固定以隔离增伤影响。需另做防御敏感性检查时单独说明，不同时改多项参数解释单一差异。
2. **统一窗口**：列开局尚未行动、前6回合主要防护与空窗、第7回合后及效果到期。按受到的伤害来源判断覆盖，不能把“毒4个目标”直接当80%来伤覆盖。反伤专项保护不代表普通攻击全覆盖。不虚构敌方行动、命中率或受击分布，未知覆盖保留区间。50%阻绝与条件75%阻绝是替换，不相加。
3. **容量锚点**：在无额外基础面板加成的同一参照下，常驻约2倍抗爆发容量通常为6分附近，2.5倍为7分附近，3–4倍为8分附近，稳定4倍以上或强开局组合通常进入9分候选。它们是校准锚点，不是单场景自动取整公式。物理专属防御不能按双路都有效；9分需在两个常规场景与窗口中有充分依据；10分需明显超出9分参照并具可靠覆盖/保命，不能仅靠峰值。特殊不死、屏障和复活另按次数、冷却、克制机制评审。
4. **条件与功能修正**：在锚点上解释覆盖、启动、一次性盾、自损造成的降档；解释可靠净化、续航、保命带来的维持或升档。一般最多一档修正；超过一档必须记录特殊机制和同定位对照。净化看触发时机、种数和冷却，不等同永久免疫。不把受击后净化回填到已承受伤害之前。
5. **普通治疗必须计入持续生存**：每次有效回复 = min(触发前缺失生命, 原回复量 × 回复修正)。实际触发次数受冷却、队友主动恢复、回合限制与次数上限约束；未发生的触发、满血溢出和致命后无法触发的回复计0。吸血以实际造成伤害为基数，不用纸面技能总倍率，禁疗/减疗时相应折减。先独立记录抗致命容量，再记录前6回合可触发的回复与第7回合后剩余渠道；受击比例回复可以很强，不应因是普通治疗而不给续航贡献。
6. **治疗与减伤存在协同**：恢复的每单位生命继续享受防御/减伤/阻绝；防護状态不变且能先存活时，其额外可承伤量为有效回复 × 当前保护倍率。动态保护逐阶段计算。不得把普通回复当作永久额外减伤，也不得把回复率直接乘进单次致命阈值。不能保证缺血和触发时，记录0到理论上限，不把上限视为实际；缺少这些条件的治疗不能独自把薄弱抗爆发角色抬到9分。
7. **面板口径**：当前参考只算明确列出的技能组合，不代表完整养成面板；最高专武生命、防御等被动需在文字复核中检查。未确认其与战斗加成的叠加层级时，不能直接把装备22%生命和技能100%相加或相乘并声称精确。可靠完成面板建模前，对比时明确排除项，不为单个角色偷偷补不同基准。
8. **成对校验**：常规场景和主要窗口内容量、净化及有效续航全面占优且无额外条件成本的角色，不能给更低分。若排序相反，必须有可追溯的条件依据，否则调整评分。对照：暑假墨瑟8（常态2倍、条件4倍）；宝拉9（技能组合无克制5.71倍、克制4.17倍，主动及被动续航）；往昔面影菲雅9（结界时无克制6.67倍、克制4.55倍，空窗3.33/2.27倍及触发净化）。
